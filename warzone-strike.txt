Drop-In TypeScript P2R Client
Copy this lightweight server-side client into your game backend to handle authentication, session start/completion, and idempotent coin spending.

TypeScript

// Drop-In TypeScript P2R Client (server-side or trusted backend)
export class P2RClient {
  constructor(
    private readonly baseUrl: string,
    private readonly gameSlug = "warzone-strike",
  ) {}

  async issueGameToken(clientId: string, clientSecret: string, platform = "web") {
    const res = await fetch(`${this.baseUrl}/api/v1/games/${this.gameSlug}/auth/token`, {
      method: "POST",
      headers: { "Content-Type": "application/json", Accept: "application/json" },
      body: JSON.stringify({ client_id: clientId, client_secret: clientSecret, platform }),
    });
    if (!res.ok) throw new Error(`Token issue failed: ${res.status}`);
    return res.json();
  }

  async startSession(gameToken: string, playerToken: string, idempotencyKey = crypto.randomUUID()) {
    const res = await fetch(`${this.baseUrl}/api/v1/games/${this.gameSlug}/sessions/start`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
        "X-Game-Access-Token": gameToken,
        Authorization: `Bearer ${playerToken}`,
      },
      body: JSON.stringify({ idempotency_key: idempotencyKey }),
    });
    if (!res.ok) throw new Error(`Start session failed: ${res.status}`);
    return res.json();
  }

  async completeSession(
    sessionId: string,
    sessionToken: string,
    bestScore: number,
    gameToken: string,
    playerToken: string,
    data: Record<string, unknown> = {},
  ) {
    const res = await fetch(`${this.baseUrl}/api/v1/games/${this.gameSlug}/sessions/${sessionId}/complete`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
        "X-Game-Access-Token": gameToken,
        Authorization: `Bearer ${playerToken}`,
      },
      body: JSON.stringify({ session_token: sessionToken, best_score: bestScore, data }),
    });
    if (!res.ok) throw new Error(`Complete session failed: ${res.status}`);
    return res.json();
  }

  async spendCoins(
    actionCode: string,
    gameToken: string,
    playerToken: string,
    idempotencyKey = crypto.randomUUID(),
  ) {
    const res = await fetch(`${this.baseUrl}/api/v1/games/${this.gameSlug}/economy/spend`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
        "X-Game-Access-Token": gameToken,
        Authorization: `Bearer ${playerToken}`,
      },
      body: JSON.stringify({ action_code: actionCode, idempotency_key: idempotencyKey }),
    });
    if (!res.ok) throw new Error(`Spend coins failed: ${res.status}`);
    return res.json();
  }
}

INTEGRATION:
Integration Status:
Documentation /INTEGRATION

INTEGRATION
Integration Status
API v1
warzone-strike
Verify your X-Game-Access-Token, credential capabilities, contract readiness, and active event context.

GET
/api/v1/games/warzone-strike/integration-status

01
Overview
Read-only by construction: it authenticates, then only reads. It creates no session, mints no token, writes no leaderboard row, and deliberately passes `recordUsage: false` so that inspecting status does not advance `last_used_at` and manufacture evidence of activity. Token-only. `client_id` / `client_secret` are never read from headers, body or query: a long-lived secret must not travel in a request to obtain a status report, and the broker already removed that distribution model. Scope is enforced by validateAccessToken() itself, which rejects a token whose `gid` is not this game before anything is returned; a mismatched token therefore surfaces as a 401/403 rather than as a body state. Every fact reported is independently checkable. Nothing here asserts that a score has ever been accepted - see `score_submission`.
